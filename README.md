# IPhySims Simulation Submissions

Submit your physics simulations for peer review and IPhySims certification.

## Submission Process

1. **Prepare Your Simulation**
2.    - Ensure code is complete and runnable
      -    - Include README with description and usage instructions
           -    - Add open-source license (GPL-3.0, MIT, Apache 2.0, or BSD)
                -    - Document all dependencies
                     -    - Provide example input/output
                      
                          - 2. **Create Metadata File**
                            3.    - Create `.iphysim/metadata.json` with simulation details
                                  -    - Include title, authors, domain, educational level, etc.
                                   
                                       - 3. **Submit via GitHub Issue**
                                         4.    - Open a new issue using the "Simulation Submission" template
                                               -    - Provide link to your simulation repository or upload files
                                                
                                                    - 4. **Review Process**
                                                      5.    - Initial screening (1-3 days)
                                                            -    - Peer review by 2 domain experts (14-21 days)
                                                                 -    - Author revision (14-30 days)
                                                                      -    - Editorial decision (3-7 days)
                                                                           -    - Publication (1-3 days)
                                                                            
                                                                                - ## Review Criteria
                                                                            
                                                                                - Simulations are evaluated on:
                                                                                - - **Scientific Accuracy** (40%)
                                                                                  - - **Code Quality** (25%)
                                                                                    - - **Reproducibility** (20%)
                                                                                      - - **Educational Value** (15%)
                                                                                       
                                                                                        - See [Review Standards](https://github.com/IPhySims/standards/blob/main/REVIEW_STANDARDS.md) for full details.
